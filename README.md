# Communication Systems Simulation Framework

An end-to-end, discrete-time Python framework designed to simulate, visualize, and analyze analog and digital communication architectures. This software platform models the complete operational lifecycle of a communication link—spanning baseband signal ingestion, passband transmitter modulation, physical channel medium propagation, mathematical receiver demodulation topologies, and digital conversion blocks.

Developed as an academic study project at the **Birla Institute of Technology & Science, Pilani**.
